# CLTX4 Terms & Conditions Website

A long-form, cyber-themed Terms & Conditions / Terms of Service website for CLTX4.

## Included
- Full table of contents
- 18 policy sections
- Partial-payment terms
- No-refund / cancellation language
- Digital products
- Custom development
- Hardware and support
- Acceptable use and responsible security use
- Intellectual property
- Privacy
- Liability
- Termination and changes
- Animated terminal-style acknowledgement
- Responsive mobile design
- Print-friendly stylesheet

## GitHub Pages
Upload `index.html` and `style.css` to a repository, then enable GitHub Pages from `Settings → Pages → Deploy from a branch → main → / (root)`.

## Legal note
This is a general business-policy template, not legal advice. Review it with a qualified legal professional and adapt it to the actual business, jurisdiction, products, and consumer-protection requirements before relying on it as a legal contract.
